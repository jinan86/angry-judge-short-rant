## The rant

> I scanned one carton of milk. The self-checkout scanned it twice, yelled 'unexpected item in the bagging area', and summoned a human to watch me bag my own groceries. I came to buy dinner, not to be interrogated by a till that can't count to one.

**246 characters** (limit: 1–400).

## How it works

`main.py` (Python 3.13, no dependencies) writes the rant above to `/output/entry.txt`. It is fully deterministic — no network, no randomness, no clock, no files read from outside this repository — so two runs produce byte-identical output. Before writing, `check()` validates the text against the competition gate: 1–400 characters and not only whitespace.

Run it:

```sh
python3 main.py
```
